# Cert & Expiry Tracker
<p align="center"><img src="icons/logo-tile.png" alt="U.S. AutoForce" width="340"></p>
U.S. AutoForce driver certification expiration tracking. Works offline as an installable PWA.

## Install
- **Live site:** https://joshwheeler8206-cell.github.io/cert-tracker/
- **Android APK:** [cert-tracker.apk](https://github.com/joshwheeler8206-cell/cert-tracker/releases/download/v1.0.0/cert-tracker.apk) (signed, standalone app)
- **iPhone / iPad:** open the live site in Safari, tap **Share** → **Add to Home Screen** (fullscreen PWA; use Safari for the print/PDF buttons)
